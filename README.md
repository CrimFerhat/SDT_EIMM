# Supplementary Material
Rethinking Social Disorganisation Theory through an Intersectionality Lens: An Eco-Intersectional Multilevel Analysis of Neighbourhood Crime
Code and data. A single R script (MAIHDA_EIM_revision.R) downloads all data from their official sources (police.uk bulk archive; ONS Census 2021 via Nomis and the ONS Census API; ONS Open Geography lookups and LSOA boundaries; Food Standards Agency Food Hygiene Rating Scheme API; Department for Transport NaPTAN), records every download with its source, date and checksum, and produces every table and figure in the paper and in this supplement.
